# LiteMC — GitHub Pages website

An independent public information site for LiteMC. The actual launcher source code remains in a **separate private repository**.

## Publish on GitHub Pages

1. Create a **new public repository**, such as `litemc-site` (do **not** change the visibility of your private launcher repository).
2. Upload `index.html` to the new repository's root and commit it to `main`. You may upload this README too.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then **Save**.
6. Once GitHub shows that the site has been published, open `https://YOUR-USERNAME.github.io/litemc-site/` in a private/incognito browser window.
7. Use that publicly accessible address for **Associated website or domain** in the Minecraft App ID review form.

## Before publication

- Verify all claims, especially sign-in and privacy behavior, against the actual LiteMC implementation.
- Add contact information if the review form or project requires it. Never expose credentials, OAuth access/refresh tokens, secrets, or private source code.
- This site does not assert that Mojang has already approved the Client ID.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
