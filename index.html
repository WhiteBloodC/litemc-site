Overview

About LiteMC

LiteMC is a third-party Minecraft: Java Edition launcher project. The software is privately developed and is not open source at this time. This website provides basic project information and explains the intended official account sign-in flow.

Independent development

Account access

Microsoft account authentication

LiteMC is being developed to support official Microsoft OAuth sign-in for users who own Minecraft: Java Edition. The intended authentication flow uses Microsoft identity services and the Xbox Live / Minecraft Services APIs to establish a valid game session.

Minecraft API access status

The project's own Microsoft Entra application is undergoing the Minecraft application ID approval process. This website does not represent that approval has already been granted.

Privacy

Authentication & privacy

Microsoft sign-in should take place through Microsoft's official authentication interface; users should not enter their Microsoft passwords into a LiteMC password form. The authentication implementation is under development. A complete privacy policy covering token storage, retention, and any diagnostics will be provided before public distribution.
