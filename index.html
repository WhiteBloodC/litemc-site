出发前，你可能想知道。

需要准备什么运行环境？+

Windows 版本需要 Windows 10 / 11 x64、WebView2 Runtime，以及匹配游戏版本的 64 位 Java；无需安装 Python。macOS 构建以 macOS 15 及以上为目标，同时支持 Apple Silicon 和 Intel。游戏的 Java 版本与架构仍需匹配。

可以使用微软账号和离线昵称吗？+

支持离线昵称及微软正版多账号。微软账号通过系统浏览器授权，启动游戏时验证 Minecraft Java 授权。离线昵称适合本地游玩，不提供游戏许可、Realms 或正版服务器认证。

模组、光影和自定义皮肤有什么要求？+

模组需匹配游戏版本与加载器。光影仅对具备相应加载能力的实例提供，需要在游戏内启用。离线自定义皮肤依赖兼容的 CustomSkinLoader；本地皮肤不会上传到微软账号，也不保证其他玩家可见。

游戏运行时，还能继续使用启动器吗？+

可以。v20 将游戏与下载任务分开管理，运行时仍可下载和管理模组、光影。新增模组在下次游戏启动后加载。取消下载不会关闭游戏；关闭启动器也会保留已启动的游戏。
